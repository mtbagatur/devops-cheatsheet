# Daily DevOps Commands

A searchable, copy-ready command reference for infrastructure, platforms, data and MLOps: Linux, networking, Git, CI/CD, Docker, Kubernetes, Helm, Terraform, Ansible, cloud CLIs, observability, databases, GPUs and model serving, plus step-by-step incident runbooks.

**Open it:** https://mtbagatur.github.io/devops-cheatsheet/

- Press `/` to search, `Esc` to clear.
- Fill **My values** once (namespace, host, bucket…) and every command is copied with your values. Values stay in your browser only.
- Star the commands you use most; they show up under **Starred**.

Single self-contained `index.html`, no build step.
